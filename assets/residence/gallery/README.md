# Bektemir Residence gallery

Eight static views of the geometry, furnishings and materials in `../scene.js`: exterior, pool, living room, kitchen, ground bedroom, upper bedroom, bathroom and cutaway plan. These are renderings of the existing model, not stock photographs of unrelated houses.

Prepared from the model on 2026-11-08 using Three.js 0.160.1 geometry and an offline OpenGL renderer. Lighting and water rendering differ from the interactive Three.js view. PBR source textures retain the credits in `../CREDITS.md`.

1600 × 1000 WebP originals and 720 × 450 card images are included. Only demo listing 21 uses this gallery and the interactive tour.
